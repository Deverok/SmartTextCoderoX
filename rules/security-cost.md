# 安全、合规与成本规则

> 依据：规格 §1.5、§8.4、§8.5、§11 全章。
> 项目定位：**单机、离线优先、数据留在本机、无账号无遥测**。任何设计都不能削弱这一点。

## 1. 密钥与凭据

- 只从 `.env`（git 忽略）或系统凭据库（Electron `safeStorage`）读取。
- 提供 `.env.example`；**禁止**把密钥写入代码、配置、日志、manifest、冻结快照。
- 冻结快照里只记录**引用名**（如 `DEEPSEEK_API_KEY`），不记录值。
- 首次启动自检：缺少必需密钥 → 明确提示，并允许进入"仅本地模式"。

## 2. 数据与隐私

| 规则 | 说明 |
|---|---|
| 默认不落原文 | 日志默认只写 `sample_id` 与摘要哈希；调试级开启需显式确认并告警 |
| 调用前提示 | 会向外部服务发送样本文本时，必须提示并记录用户确认状态（规格 §8.5） |
| 纯本地路径 | 提供"离线模式"：仅关键词引擎/规则引擎/本地 ASR、本地 OCR，全程零外呼 |
| 示例数据 | 必须是**合成或已授权**数据，不得含真实个人信息；`data/_example/README.md` 写明来源与许可 |
| 真实数据不入库 | `.gitignore` 强制（`data/` 除 `_example/` 外全忽略）+ 提交前检查脚本 |
| 无遥测 | 禁止任何形式的上报/埋点/崩溃上传 |

## 3. 成本控制

- **编码前预估**：样本数 × 题目数 × 平均 token × 单价 → 展示估计区间（GUI 与 CLI 都要）。
- **硬熔断**：`budget.max_amount` / `budget.max_calls` 达阈值即暂停，可恢复。
- **记账**：每次调用写 `llm.jsonl`；汇总写 `logs/{v}/{run}/cost.json`（金额、调用数、token 入/出、缓存命中、按模型与按步骤拆分、是否估算值）。
- **缓存优先**：命中缓存不重复计费；`cacheTtl` 不得配置为 0（等于每次都烧钱）。
- **计划任务**：默认**禁止**自动调用付费模型；必须显式 `--allow-paid` 才放行（规格 §16.2）。
- **决策型来源**：只走托管 API；未过准入门槛不得启用（否则既花钱又污染信度）。

## 4. 依赖与许可

- 主许可：**Apache-2.0**；第三方依赖必须与之一致（宽松许可）。
- **禁止**引入 AGPL 等传染性许可进入内核链路；PDF 处理用 `pypdf`/`pdfplumber`，不用 PyMuPDF。
- **ffmpeg**：只用 LGPL 构建，以**独立进程**调用（不静态链接、不改其源码），随包附许可全文与源码获取指引。
- 新增依赖必须说明：用途、体积影响、许可证、是否可移除。
- `lib/licenses/` 保存许可全文；`THIRD_PARTY_NOTICES.md` 由 CI 校验与依赖清单一致。

## 5. 打包与分发（MS5 起）

- Python sidecar 用 PyInstaller **onedir**（不用 onefile：启动慢、易被安全软件误报）。
- 随包资源必须显式声明，否则打包后必坏：`lib/fonts/`、`lib/stopwords/`、`lib/dicts/`、分词数据、`lib/bin/ffmpeg`（若随包）、`data/_example/`。
- 首次启动自检：字体、ffmpeg、sidecar 可执行、模型配置完整性；缺项给可操作指引。
- 体积预算 `[SHOULD]` < 300 MB（本地模型按需下载）。
- macOS：注意文件名 NFD 与签名/公证；Windows：注意 SmartScreen。

## 6. 环境变量约定

| 变量 | 用途 |
|---|---|
| `STCX_WORKSPACES_ROOT` | 运行区根（默认仓库根） |
| `STCX_HOME` | 应用配置与缓存根（可选） |
| `DEEPSEEK_API_KEY` / `ZHIPU_API_KEY` / … | 模型密钥（按 provider 命名，配置中只引用名） |
| `STCX_OFFLINE` | `1` = 强制离线模式（禁用一切外呼） |

- 环境变量**只**承载密钥与根路径，**禁止**用它传业务数据。

## 7. 合规声明（随仓库提供）

- `SECURITY.md`：如何报告漏洞、支持的版本、密钥处理说明。
- README 与报告模板必须包含：本工具为**研究辅助**；使用者对编码规则设计、抽样与信度解释负全责；**AI 编码结果必须经人工抽样校验**。
- 报告中自动生成"**AI 参与程度声明**"：哪些字段由 AI 编码、人工复核比例、模型与版本、提示词哈希。
- 商标：不得在项目名、界面、宣传中使用他方商标（如 DiVoMiner）作暗示；对比引用需注明来源。

## 8. 禁止事项

1. 记录/打印密钥或样本文本原文。
2. 未提示就向外部服务发送研究数据。
3. 把真实研究数据提交进仓库。
4. 引入传染性许可依赖。
5. 加入任何遥测。
6. 计划任务里默认烧付费额度。
